# PoE 2 Tracker – releases

Downloads for **PoE 2 Tracker**, a Windows desktop app for tracking Path of Exile 2 farming runs, drops and earnings, with live prices from poe.ninja. Everything is entered by hand. The app never reads game files or talks to the game.

## Install

1. Open the [latest release](../../releases/latest) and download the `.zip` file.
2. Unzip it anywhere, open the `PoE 2 Tracker` folder and start `PoE 2 Tracker.exe`.
3. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. This only happens the first time.

## Updates

The app checks this page for new versions by itself and asks before installing one. Your runs, drops, prices and layouts are stored separately in `%APPDATA%\poe2-drop-tracker` and are never part of an update.

This repository holds only the release files.
