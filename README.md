# PoE 2 Tracker – releases

Downloads for **PoE 2 Tracker**, a Windows desktop app for tracking Path of Exile 2 farming runs, drops and earnings, with live prices from poe.ninja. Everything is entered by hand. The app never reads game files or talks to the game.

## Install

1. Open the [latest release](../../releases/latest) and download **`PoE-2-Tracker-Setup.exe`**. That's the only file you need.
2. Run it. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. Your browser may also ask whether to keep the file; choose to keep it. This only happens the first time.
3. Choose where to install it and whether you want a desktop shortcut. The installer then downloads the app (about 150 MB) and sets everything up, including a Start menu entry.

Needs Windows 10 or 11 (64-bit) and an internet connection while installing. No administrator rights are needed.

## Updates

The app checks for a new version every time it starts and asks before installing it. If you choose **Install now**, it closes, updates itself and starts again.

Your runs, drops, prices and layouts are stored separately in `%APPDATA%\PoE2Tracker`. They are never part of an install, update or uninstall.

## Uninstall

Windows Settings → Apps → Installed apps → **PoE 2 Tracker** → Uninstall. Your data stays in `%APPDATA%\PoE2Tracker` unless you delete that folder yourself.
